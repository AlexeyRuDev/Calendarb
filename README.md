# 📅 Календарь задач (Desktop, Python + Tkinter)

Приложение с месячным календарём: клик по любой ячейке дня открывает
отдельный экран со списком задач на выбранный день.

## Возможности
- Месячный календарь (неделя с Пн), навигация `‹ ›` по месяцам и кнопка «Сегодня».
- Подсветка текущего дня и индикатор `• N из M` (выполнено из общего числа) прямо в ячейке.
- **Клик по ячейке → отдельный экран дня** со списком задач.
- На экране дня: добавление задач (Enter или кнопка «Добавить»), отметка «выполнено»
  (зачёркивание), удаление (✕).
- Все задачи сохраняются в `tasks.json` рядом с файлом приложения.

## Запуск
```bash
python calendar_app.py
```
Требуется только стандартная библиотека (Tkinter идёт в составе Python;
в некоторых Linux-дистрибутивах нужен пакет `python3-tk`).
